# ODPMX

Estructura separada por páginas:

- HTML individual para cada sección.
- CSS global + CSS por página.
- JS global + JS por página.
- `data/casos.json` para pruebas.
- Backend opcional en Python Flask.

Para abrir el frontend, usa `index.html`.

Para probar el backend:

```bash
cd backend
pip install -r requirements.txt
python app.py
```
