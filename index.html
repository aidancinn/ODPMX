Plataforma ciudadana

Un espacio para preservar memoria y visibilizar búsquedas.

ODPMX nace como una plataforma digital y archivo en expansión. Su propósito inicial es reunir información pública, autorizada y tratada con respeto sobre casos de desaparición, evitando el morbo, la especulación y cualquier contenido que pueda afectar investigaciones o familias.

La plataforma crecerá por etapas: primero diseño, estructura y búsqueda básica; posteriormente almacenamiento de casos, formularios, revisión de información y, más adelante, backend, base de datos y panel administrativo.

Cómo utilizar la plataforma

Buscar, leer y compartir con responsabilidad.

1. Buscar casos

Utiliza el buscador por nombre, estado, fecha o palabra clave. Los filtros ayudarán a encontrar información de manera más sencilla.

2. Revisar información

Cada publicación debe contener únicamente información pública, autorizada o verificada, evitando acusaciones o señalamientos.

3. Compartir con respeto

La difusión debe preservar la dignidad de las personas y de sus familias. La memoria nunca debe convertirse en espectáculo.

Proceso de expansión

Esta plataforma crecerá de forma gradual.

ODPMX comenzará como una página informativa. Con el tiempo podrá integrar backend en Python, base de datos, panel privado, formularios de contacto y un sistema de revisión para publicar casos con mayor seguridad y organización.
