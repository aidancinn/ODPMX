Plataforma ciudadana

Un espacio para preservar memoria y visibilizar búsquedas.

ODPMX nace como una web-page y archivo digital en expansión. Su objetivo inicial es reunir información pública, autorizada y tratada con respeto sobre casos de desaparición, evitando el morbo, la especulación y cualquier contenido que pueda afectar investigaciones o familias.

La plataforma crecerá por etapas: primero diseño, estructura y búsqueda básica; después almacenamiento de casos, formularios, revisión de información y, más adelante, backend con base de datos.

Cómo usar la búsqueda

Buscar, leer y compartir con responsabilidad.

1. Buscar casos

Usa el buscador por nombre, estado, fecha o palabra clave. Los filtros ayudarán a encontrar información más rápido.

2. Revisar información

Cada nota debe mostrar únicamente información autorizada, pública o verificada, sin señalar culpables ni hacer acusaciones.

3. Compartir con respeto

La difusión debe cuidar la dignidad de las personas y familias. La memoria no debe convertirse en espectáculo.

Proceso de expansión

Esta plataforma crecerá de forma gradual.

ODPMX empezará como una página informativa. Con el tiempo podrá integrar un backend en Python, base de datos, panel privado, formularios de contacto y un sistema de revisión para publicar casos con mayor seguridad y orden.
